# Limitations

The original Stage-0 run found variable historical coverage, legacy PV aliases, heterogeneous cadences and gaps. The fill list does not state a timezone; America/Chicago was assumed. The four labels are operational descriptions at APS granularity. They are not verified root causes and do not encode treatments, counterfactuals or causal engineering interventions.

The public interface is suitable for a reproducible observational benchmark only while its services and historical records remain available. A changed count must be reported, not overwritten or normalized to match the reference.
