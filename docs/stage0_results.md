# Stage-0 reference results

The original run reported 170,547 uncompacted numeric observations, six successful PVs, four official fill-termination events and 75,992 observations within ±2 hours of those events. Median cadences were 1, 8, 32, 64, 16 and 16 seconds in configured PV order.

These values are stored as an explicit historical reference in `results/reference_stage0.json`. The pipeline calculates current values independently and reports every difference. They are feasibility and QA statistics, not evidence for superiority of any model.
